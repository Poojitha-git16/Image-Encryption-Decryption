💡 How to Get File Paths

Windows:

  1. Select files in File Explorer
  2. Hold Shift and right-click
  3. Choose "Copy as path"

macOS:

  1. Select files in Finder
  2. Right-click and hold Option
  3. Choose "Copy [filename] as Pathname"

Linux:

  1. Select files in file manager
  2. Right-click and choose "Copy"
  3. Paste in terminal and use `pwd` for full paths
